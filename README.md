# BlendHubApp

**Unified Business Workspace for Windows**

BlendHubApp brings your communication and work tools together in a single desktop application.

Use WhatsApp, Telegram, Microsoft Teams, Slack, Gmail, Google Drive and custom workspaces from one interface without constantly switching between separate apps and browser tabs.

## Supported workspaces

- WhatsApp
- Telegram
- Microsoft Teams
- Slack
- Gmail
- Google Drive
- Custom web workspaces

## Key features

- Multiple accounts and workspaces in one application
- Isolated sessions for separate accounts
- Unified workspace navigation
- Split Work View
- Quick Notes
- Desktop notifications
- Custom workspace support
- Automatic application updates

## Automatic updates

You only need to install BlendHubApp once.

After installation, future application updates are delivered automatically through BlendHubApp's update system. You do not need to return to GitHub and manually download every new version.

## Installation

1. Open the **Releases** section.
2. Download the latest `BlendHubApp-Setup-*.exe` file.
3. Run the installer.
4. Launch BlendHubApp.

## System requirements

- Windows 10 or Windows 11
- Internet connection
- Access to the services you want to use inside BlendHubApp
